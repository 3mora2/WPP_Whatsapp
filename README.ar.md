# WPP_Whatsapp

**أتمتة WhatsApp Web باستخدام Python.**

أنشئ تطبيقات تستقبل الرسائل، وتقرأ المحادثات، وتتعامل مع الوسائط، وتربط واتساب
بعملاء MCP. تجمع المكتبة بين
[WPPConnect](https://github.com/wppconnect-team/wppconnect)
و[WA-JS](https://github.com/wppconnect-team/wa-js) وPlaywright، وتوفر واجهة متزامنة
وأخرى تدعم `asyncio` مباشرة.

## ماذا يمكنك أن تبني؟

- **تطبيقات للتعامل مع الرسائل:** استقبال الرسائل الواردة، وقراءة سجل المحادثات،
  وإرسال النصوص، والرد على الرسائل.
- **تكاملات للوسائط:** إرسال الصور والمستندات، وتنزيل وسائط الرسائل.
- **أدوات لجهات الاتصال والمجموعات:** البحث عن جهة اتصال، وعرض المحادثات وأعضاء المجموعات.
- **تطبيقات غير متزامنة:** استخدام خدمات `asyncio` للرسائل والمحادثات والأحداث،
  مع إمكانية الحصول على نتائج قراءة ذات أنواع محددة.
- **تكاملات MCP:** إتاحة أدوات واتساب عبر stdio أو HTTP محلي، مع عزل الحسابات،
  وسياسات الوصول، والتشخيص، وتتبع عمليات الإرسال.

## التثبيت

تحتاج إلى **Python 3.9 أو أحدث**، و**Chrome أو Chromium الخاص بـPlaywright**، واتصال بالإنترنت.
يتطلب تكامل MCP الاختياري **Python 3.10 أو أحدث**.

لتثبيت مكتبة Python:

```bash
python -m pip install --upgrade WPP_Whatsapp
```

إذا كنت تحتاج إلى MCP، فاستخدم أمر التثبيت التالي بدلًا منه:

```bash
python -m pip install --upgrade "WPP_Whatsapp[mcp]"
```

تستخدم المكتبة Chrome افتراضيًا، ويمكنك أيضًا استخدام Chromium الخاص بـPlaywright.
راجع [دليل التثبيت](docs/INSTALLATION.md) لإعداد المتصفح ومعرفة خيارات FFmpeg
وإضافة `stealth` الاختيارية.

## بداية سريعة: استقبال الرسائل

احفظ المثال التالي في ملف باسم `listener.py`، ثم شغّله بالأمر `python listener.py`:

```python
from threading import Event

from WPP_Whatsapp import Create


def incoming(message):
    print("معرّف الرسالة الواردة:", message.get("id"))


with Create(session="mybot", autoClose=0) as client:
    client.onMessage(incoming)
    print("بانتظار الرسائل؛ اضغط Ctrl+C للإغلاق.")
    Event().wait()
```

عند التشغيل لأول مرة، امسح رمز QR الظاهر في المتصفح باستخدام واتساب على هاتفك.
استخدم اسم الجلسة نفسه في المرات التالية لإعادة استخدام تسجيل الدخول المحفوظ.
يطبع المثال معرّفات الرسائل الواردة، ويستمر في الاستماع حتى تضغط Ctrl+C.
عند الخروج من كتلة `with`، تُغلق موارد العميل مع الاحتفاظ بتسجيل الدخول.

يتولى `Create` بدء الجلسة، ويعيد العميل الجاهز عند الدخول إلى كتلة `with`.
إذا كنت تدير بدء التشغيل بنفسك، فاستخدم `creator.start()` للحصول على العميل
قبل تسجيل دوال استقبال الرسائل أو استدعاء أساليبه.

## استخدام asyncio

استخدم `AsyncClient` إذا كان تطبيقك يعتمد على `asyncio`.
يجلب هذا المثال عشر محادثات كحد أقصى:

```python
import asyncio

from WPP_Whatsapp import AsyncClient


async def main():
    async with AsyncClient("mybot", autoClose=0) as client:
        chats = await client.chats.list_chats({"count": 10})
        print("عدد المحادثات المحمّلة:", len(chats))


asyncio.run(main())
```

استخدم كل عميل غير متزامن داخل حلقة الأحداث التي أنشأته.
تستخدم الخدمات الأصلية أسماء أساليب بصيغة `snake_case`، بينما تحتفظ الأساليب
المباشرة القديمة بأسمائها ونتائجها الخام.
راجع [مرجع API](docs/API_REFERENCE.md) لأمثلة الإرسال والسجل والوسائط،
و[دليل الانتقال](docs/ARCHITECTURE.md) لتحديث الكود القديم إلى الخدمات الأصلية.

## الربط بعميل MCP

بعد تثبيت إضافة `mcp`، اضبط عميل MCP لتشغيل الأمر التالي:

```bash
wpp-whatsapp-mcp --session mybot
```

يستخدم هذا الأمر اتصال stdio. لتشغيل خادم HTTP محلي بدلًا منه:

```bash
wpp-whatsapp-mcp --session mybot --transport http --port 8765
```

عنوان الاتصال المحلي هو `http://127.0.0.1:8765/mcp`.
بعد تشغيل الخادم:

1. استدعِ `whatsapp_connect` من عميل MCP.
2. أكمل تسجيل الدخول إلى واتساب داخل المتصفح.
3. كرّر الاستعلام باستخدام `whatsapp_status` حتى تصبح قيمة `ready` هي `true`.

تشغيل خادم MCP وحده لا يفتح واتساب. يوفر الإصدار **2.3.0**
**23 أداة** للجلسات والمحادثات والرسائل والبحث والأحداث والوسائط والتشخيص ومتابعة الوصول والقراءة.
استخدم `--read-only` لاستبعاد أدوات الإرسال وتسوية نتائج الإرسال غير المؤكدة؛
عندها تتبقى **18 أداة**.

يشرح [دليل FastMCP](docs/FASTMCP.md) إعداد العميل، وتعدد الحسابات، وسياسات
الوصول باستخدام رموز JWT المتحقق منها، وتتبع الإرسال.
ظهر دعم MCP في الإصدار 2.1.0 مع 12 أداة؛ وتتطلب المجموعة الموسعة الإصدار 2.2.0 أو أحدث.

يضيف الإصدار 2.3.0 ربط معرّف الإرسال بطلبه، وحفظ الأحداث اختياريًا، واستعادة اتصال
محدودة، وانتظار دليل الوصول والقراءة، وحدودًا للتزامن ومعدل الإرسال.
راجع [دليل الاعتمادية والترقية](docs/RELIABILITY.md) و[حالة الإصدار](CHANGELOG.md)
وأمثلة HTTP وMCP القابلة للتشغيل.

## التعامل مع الجلسات ونتائج الإرسال

- **استخدم الجلسات بصورة متسقة.** لا يمكن تشغيل أكثر من عميل على ملف المتصفح نفسه
  في الوقت نفسه. أغلق العميل الحالي قبل إعادة استخدام الملف؛ الخيار
  `close_already_profile=True` غير مقبول.
- **احتفظ بالمعرّفات كاملة.** لا تختصر معرّفات الرسائل، بما في ذلك لاحقة المشارك
  في رسائل المجموعات. تُفسَّر أرقام الهواتف المجردة كأرقام هواتف؛ أما معرّفات LID
  الصريحة فتستخدم اللاحقة `@lid`.
- **تحقق من نتيجة الإرسال قبل إعادة المحاولة.** تعيد خدمات الإرسال المتتبَّع
  إيصالات لنتائج العمليات. تأكيد معرّف الرسالة لا يثبت وصولها إلى المستلم أو قراءتها.
  راجع [سلوك الإرسال](docs/ARCHITECTURE.md#sending-and-uncertain-results)
  قبل إضافة إعادة محاولات تلقائية.
- **اختر نسخة التشغيل عند الحاجة.** يبحث بدء التشغيل افتراضيًا عن أحدث إصدار مستقر
  من WA-JS، ثم يتحقق من النسخة المخبأة، مع الرجوع إلى الملفات المرفقة عند الحاجة.
  استخدم `wa_js_version="bundled"` لتجاوز البحث والتنزيل؛ ويظل واتساب بحاجة إلى الإنترنت.
  عند تحديد إصدار أو رابط أو ملف صراحةً، تلتزم المكتبة بهذا الاختيار دون استبداله تلقائيًا.
- **راجع الإعدادات الاختيارية.** يتطلب `stealthy=True` تثبيت `WPP_Whatsapp[stealth]`.
  تختلف وحدات المهلة بين الإعدادات؛ راجع [دليل الإعدادات](docs/CONFIGURATION.md).

النسخ المرفقة: WPPConnect **2.3.4** وWA-JS **4.6.1**.

## المساهمة والدعم

للإبلاغ عن خطأ، افتح [مشكلة على GitHub](https://github.com/3mora2/WPP_Whatsapp/issues)
وأرفق مثالًا صغيرًا يعيد إنتاجه، مع معلومات الإصدار والخطأ بعد إزالة البيانات الحساسة.
للمساهمة في الكود، ابدأ بـ[دليل التطوير](docs/DEVELOPMENT.md)
و[دليل الاختبارات](tests/README.md).
يمكنك متابعة تغييرات الإصدارات في [سجل التغييرات](CHANGELOG.md).

تستخدم اختبارات MCP الآلية عمليات واتساب محاكاة عبر وسائل نقل MCP حقيقية؛
ولا تثبت نجاح الإرسال الفعلي أو توافق كل واجهات المكتبات الأساسية.
تحدد آلية تقييد المعدل المحلية وتيرة العمليات، ولا تضمن قبول المنصة لها أو حماية الحساب من الحظر.
